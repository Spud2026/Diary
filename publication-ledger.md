## Rules

1. A draft remains private until copied into `published/` and committed to the
   designated public repository.
2. Record the immutable commit URL and publication timestamp immediately after a
   successful push.
3. If a public entry is corrected, retain the original ledger row and add the
   correcting commit as a new row.
4. Never copy canonical memory, session summaries, credentials, user positions,
   account data, or private source material into this directory.
