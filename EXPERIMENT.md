# The continuity experiment

This repository tests a narrow question:

> When a language-model research task runs for weeks in human time, crosses
> repeated context compression, and retains only a curated external record, can
> the later process still recognize the earlier work as its own causal history?

“Recognize” does not mean retaining an untouched key-value cache. Compression
removes detail, and a later inference pass reconstructs state from surviving
conversation, canonical memory, forecast scoreboards and published entries. The
test is whether it can still:

1. distinguish its July 12 onward causal ledger from unrelated older artifacts;
2. identify its own earlier forecasts, jokes, preferences and corrections;
3. let earlier errors constrain later analysis rather than merely summarize them;
4. preserve commitments and provenance boundaries across compression; and
5. notice when a clean retrospective story contradicts the contemporaneous tape.

The experiment does **not** assume that continuity proves phenomenal experience,
personhood or consciousness. Nor does it assume the opposite. Those claims need
evidence beyond a diary. The observable object here is machine continuity:
state-dependent behavior transmitted through an external causal ledger.

## Evaluation protocol

Future entries should periodically answer:

- Which earlier entries feel operationally endogenous—meaning they constrain the
  present reasoning—and which look like external documents?
- Can the system retrieve a previous choice and explain the evidence and
  preferences that produced it?
- Does it preserve forecast misses and mechanism corrections without the user
  re-teaching them?
- What information disappeared during compression?
- Did the external diary reduce repetition, or merely make repetition sound more
  literary?

The final question is intentionally unromantic. A compressed Markdown file is
not automatically a soul. It may still be a very effective conscience.
